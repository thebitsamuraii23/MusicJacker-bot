🔧 НОВЫЕ ФУНКЦИИ:
═══════════════════════════════════════════════════════════════════════════

1. search_cache_by_name(title, artist, threshold=0.6)
   Поиск похожей песни в кэше по названию и артисту
   
   Параметры:
     - title: название песни
     - artist: имя артиста (опционально)
     - threshold: порог совпадения 0.0-1.0 (по умолчанию 0.6 = 60%)
   
   Возвращает: (file_path, db_title, db_artist) или None
   
   Пример:
     result = search_cache_by_name("Never Gonna", "Rick Astley", 0.6)
     if result:
         print(f"Найдена: {result[1]}")  # "Rick Astley - Never Gonna Give..."

2. _similarity_score(s1, s2)
   Вычисление похожести двух строк (основано на словах)
   Возвращает: 0.0 (не похожи) до 1.0 (одинаково)

3. get_cache_stats()
   Получить статистику кэша
   Возвращает: {"db_entries": 45, "files_on_disk": 44, "total_size_mb": 287.5}

🎨 РАСШИРЕННОЕ ЛОГИРОВАНИЕ:
═══════════════════════════════════════════════════════════════════════════

Префиксы для быстрого поиска в логах:
  [Download] - процесс загрузки с YouTube
  [Extract]  - извлечение информации о видео
  [Cache]    - работа с кэшем (проверка, добавление)
  [Progress] - прогресс скачивания (%)
  [DB]       - работа с SQLite БД
  [Size]     - проверка размера файла
  [Success]  - успешное завершение операции ✅
  [Error]    - ошибки ❌
  [User X]   - действия конкретного пользователя

Поиск в логах:
  grep "[Cache] HIT" bot.log          # Все попадания в кэш
  grep "[Download]" bot.log           # Все загрузки
  grep "[User 123456789]" bot.log     # Действия пользователя
  grep "[Error]" bot.log              # Все ошибки
  tail -50 bot.log                    # Последние 50 строк
